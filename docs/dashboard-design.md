# Football dashboard direction

Design read: a compact matchday control room based on the user's [first Pinterest reference](https://id.pinterest.com/pin/389842911516422475/), [second Pinterest reference](https://id.pinterest.com/pin/7810999344691163/), and [bwin Dribbble shot](https://dribbble.com/shots/6539784-bwin). The desktop layout now uses a horizontal navigation bar, a narrow icon rail on the right, and a dark featured fixture stage. Large club crests take the place of player photography.

Graphite surfaces keep the fixture list readable; lime marks selected navigation, active competitions, and primary actions. The feature card uses room team names, kickoff time, competition, and match question. Known real clubs use crests from [football-data.org](https://www.football-data.org/documentation/quickstart); unknown clubs keep a monogram fallback. Demo rooms are fictional and never show a real crest as if a real fixture were scheduled.

The second Pinterest reference is an 11-second motion study: its editorial story changes, a pale match-detail panel slides in from the left, then the view returns to the story. Sober translates this into an automatically advancing featured-fixture carousel, quick-selection rail, and a light match-details panel. The photo and content transition when the fixture changes. Hover, focus, an open details panel, reduced-motion preference, or a hidden tab pauses automatic advancement. Arrow controls, fixture dots, a pause/play control, and Escape-to-close keep the sequence under user control. Reduced-motion mode disables automatic advancement and entrance animation.

The home dashboard includes only kickoff times in the future. In live mode it requires a published, reviewed Sober room for fixture data, then looks up its mapped market in the Panta market list and detail API before showing a Panta phase. Panta markets do not supply a verified kickoff or club identity to this UI on their own. When no API key is configured, the page says so; in simulation it labels all fixtures fictional. It does not invent scores, odds, standings, form, or live indicators. Competition chips, search, date filters, save controls, and navigation retain their working behavior. On phones the sidebar becomes a drawer and the four primary destinations move to a bottom bar.
